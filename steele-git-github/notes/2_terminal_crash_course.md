## Navigation
- `ls` - List the current contents of your current directory. 
    - Can be used on a folder as well --> `ls learning`.
    - If multiple levels away, you have to type the path --> ls learning/steele-git-github.
- `start .` - Opens up the current directory in the file explorer.
    - Can be used on a folder as well --> `start learning`.
- `pwd` - Prints the path to the working directory (where you currently are).
- `cd` - Change and move between folders. How we move around. Equivalent of double clicking on a folder. 
    - `cd steele-git-github` <-- Go into the steele-git-github folder.
    - `cd ..` <-- Go up one level in your directory.

## Creating Files and Folders
- `ni <file_name>` - Use this to create a file in your current directory.
- `ni <file_name1>,<file_name2>,<file_name3>` - Making multiple files in your current directory.
- `ni learning-archive/steele-git-github/test.py` - Makes a test.py folder in the steele-git-github while I'm in my home directory. 
- `mkdir <directory>` - How to make a directory(folder)
    - Can also make folders in certain locations by passing in the path to that location.

## Deleting Files and Folders
- `rm <file_name>` - Deletes a file from the directory you are currently in. 
- `rm <path_to_file> - Deletes a file from a different directory by providing the file path.
