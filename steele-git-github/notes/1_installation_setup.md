## Two Ways to Interract with Git
- Git is primarily a terminal tool
    - Not the most user-friendly experience, but it's at the core of Git. 
- Git can be used in a GUI
    - These add a graphical interface that allows people that are less technical to use Git. 
- There is a lot of GUI gate keeping. 

## Installing Git
- Visit https://git-scm.com/install/ and install Git.

## Configuring Your Git Name and Email
- You have to tell Git who you are and who to attribute work to on our machine. 
    - This really helps you to keep track of who does what in a collaboration environment. 
- `git config --global user.name "Ian B Princic"` <-- Configure name that Git associates with you
- `git config user.name` <-- See what name Git associates with you currently
- `git config --global user.email <your email>` <-- Configures what email Git associates with you
- `git config user.email` <-- See what email Git associates with you currently
